Docker networking
Docker networking lets containers communicate with each other, the host, and external networks.

Common network types:

bridge — Default for containers on a single Docker host. Containers on the same user-defined bridge can communicate by container name.

host — Container shares the host's network stack; no separate container IP.

none — Disables networking.

overlay — Connects containers across multiple Docker hosts, commonly with Docker Swarm.

Useful commands:

docker network ls
docker network inspect bridge
docker network create mynet
docker run --network mynet --name app nginx

Example:

app ──┐
      ├── mynet ── Docker host ── Internet
db  ──┘
